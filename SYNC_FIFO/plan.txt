1.create mem data_widthxdepth
2.rd,wr width = log2depth
3..count width = lod2(depth+1)
commands:
1.only write--->full? refuse, else write at wr_ptr, (wr_ptr++)%depth count++
2.only read--->empty? refuse, else read at rd_ptr, (rd_ptr++)%depth count--
3.write+read--->full or not full and not empty?read,then write
            --->empty?write only
how to check empty or full?
  empty = rd_ptr==wr_ptr and count = 0
  full = count == depth
on reset---> rd,wr ptr become zero, dataout is also set to zero
